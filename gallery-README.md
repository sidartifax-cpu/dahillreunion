# Da Hill Gallery Images

Drop any photo into this folder and push to GitHub.
The gallery manifest will automatically update and your photo will join the rotation.

**Supported formats:** .jpg, .jpeg, .png, .gif, .webp

**How it works:**
1. Add photo(s) to this folder via Finder on your MyCloud
2. Go to GitHub Desktop
3. Commit with message like "Add reunion photos"
4. Push origin
5. GitHub automatically rebuilds the gallery — done

**The gallery page randomly selects 60 photos from all images here on every page load.**
Different visitors see different photos. Every refresh shows a new set.

Over 40 years of reunions — every photo belongs here.
